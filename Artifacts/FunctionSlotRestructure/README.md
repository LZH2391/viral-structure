# FunctionSlotRestructure

Default landing area for function-slot recomposition markdown outputs.

Generated plans should be written under:

```text
Artifacts/FunctionSlotRestructure/<briefSlug-or-runId>/restructure.final.md
```

If no stable brief slug or runId is available, use a local timestamp directory such as:

```text
Artifacts/FunctionSlotRestructure/restructure-YYYYMMDD-HHMMSS/restructure.final.md
```

Generated plan files are ignored by default; keep only this README in git.
